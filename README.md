# Event-Driven Metaheuristic Optimization

Dynamic resource allocation and scheduling via event-driven metaheuristics
(Genetic Algorithm + Differential Evolution) with stateful / warm-start optimization.

Core problem:

    min_x f_t(x)   subject to   g_{i,t}(x) <= 0

where objective and constraints may change over time.
